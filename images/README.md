# Папка для изображений

Здесь размещайте все изображения для сайта:

- `hero.jpg` - главное изображение Hero-блока
- `technology/` - изображения этапов технологии
- `advantages/` - изображения для раздела преимуществ
- `readiness/` - изображения уровней готовности
- `projects/` - изображения проектов домов
- `custom/` - изображения для индивидуальных проектов

**Формат:** 4:3 (например, 1920×1440px)  
**Разрешение:** минимум 1920px по большей стороне
