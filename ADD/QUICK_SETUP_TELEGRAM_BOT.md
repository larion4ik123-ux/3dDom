# Быстрый старт: Настройка Telegram бота (10 минут)

## ⚡ За 10 минут до работающего бота

### 1️⃣ Создание бота (3 минуты)

1. Откройте Telegram
2. Найдите [@BotFather](https://t.me/botfather)
3. Отправьте: `/newbot`
4. Придумайте имя: `Home3D Requests`
5. Придумайте username: `home3d_requests_bot`
6. **Скопируйте токен** (например: `123456789:ABCdef...`)

---

### 2️⃣ Создание канала (3 минуты)

1. В Telegram: "Новый канал"
2. Название: "Home3D Заявки"
3. Настройки канала → "Администраторы" → "Добавить администратора"
4. Найдите вашего бота (`@home3d_requests_bot`)
5. Дайте права: ✅ "Отправлять сообщения"
6. Добавьте пользователей в канал (кто должен получать заявки)

---

### 3️⃣ Получение Chat ID (2 минуты)

**Самый простой способ:**

1. Добавьте бота [@getidsbot](https://t.me/getidsbot) в ваш канал
2. Отправьте любое сообщение в канал
3. Бот покажет Chat ID (например: `-1001234567890`)
4. **Скопируйте Chat ID**

**Альтернативный способ:**

1. Откройте: `https://api.telegram.org/botВАШ_ТОКЕН/getUpdates`
2. Найдите `"chat":{"id":-100...}`
3. Скопируйте число после `"id":`

---

### 4️⃣ Подключение к сайту (2 минуты)

**Откройте `js/main.js` и добавьте в начало:**

```javascript
// Конфигурация Telegram
const TELEGRAM_CONFIG = {
    BOT_TOKEN: 'ВАШ_ТОКЕН',      // Вставьте токен из шага 1
    CHAT_ID: 'ВАШ_CHAT_ID'        // Вставьте Chat ID из шага 3
};
```

**Замените:**
- `ВАШ_ТОКЕН` → токен из шага 1
- `ВАШ_CHAT_ID` → Chat ID из шага 3

**Добавьте функции** из `js/main-telegram-complete.js` или `js/main-telegram-email-complete.js`

**Замените функцию `handleFormSubmit`** на версию с Telegram

---

### 5️⃣ Тестирование (1 минута)

1. Откройте сайт
2. Заполните форму
3. Отправьте заявку
4. Проверьте Telegram канал - должно прийти сообщение! ✅

---

## ✅ Готово!

Теперь все заявки будут приходить в ваш Telegram канал, и все участники канала будут получать уведомления!

---

## 🔧 Если что-то не работает

**Бот не отправляет сообщения:**
- ✅ Проверьте, что бот добавлен в канал как администратор
- ✅ Проверьте правильность токена и Chat ID
- ✅ Откройте консоль браузера (F12) и проверьте ошибки

**Не получаете уведомления:**
- ✅ Проверьте настройки уведомлений Telegram
- ✅ Убедитесь, что вы добавлены в канал
- ✅ Проверьте, что канал не отключён в уведомлениях
