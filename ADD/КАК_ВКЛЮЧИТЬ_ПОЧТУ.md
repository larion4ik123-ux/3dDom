# Как включить отправку заявок на почту

Сейчас заявки уходят **в Telegram**. Чтобы они дублировались **на вашу почту**, настройте EmailJS (бесплатно, без своего сервера).

## Шаг 1: Регистрация

1. Зайдите на [https://www.emailjs.com/](https://www.emailjs.com/)
2. Зарегистрируйтесь и подтвердите email.

## Шаг 2: Подключите почту

1. В панели: **Email Services** → **Add New Service**
2. Выберите вашего почтового провайдера (Gmail, Mail.ru, Яндекс и т.д.) и следуйте подсказкам.
3. Запомните **Service ID** (например `service_xxxxx`).

## Шаг 3: Шаблон письма

1. **Email Templates** → **Create New Template**
2. **Subject (тема):** например: `Новая заявка с сайта Home3D`
3. **Content (тело письма)** можно сделать таким:

```
Тип заявки: {{form_type}}
Дата: {{date}}

Имя: {{name}}
Телефон: {{phone}}
Email: {{email}}

Сообщение:
{{message}}

Дополнительно (для индивидуального проекта):
Площадь: {{area}} м²
Этажность: {{floors}}
Уровень готовности: {{readiness}}
```

4. Сохраните шаблон и скопируйте **Template ID** (например `template_xxxxx`).

## Шаг 4: Ключи в коде

1. В личном кабинете EmailJS откройте **Account** → скопируйте **Public Key**.
2. Откройте файл **`js/main.js`** в редакторе.
3. Найдите блок **EMAILJS_CONFIG** (в начале файла) и подставьте свои значения:

```javascript
const EMAILJS_CONFIG = {
    PUBLIC_KEY: 'ваш_public_key',
    SERVICE_ID: 'ваш_service_id',
    TEMPLATE_ID: 'ваш_template_id'
};
```

4. Сохраните файл.

После этого при каждой отправке заявки с сайта:
- заявка по-прежнему уходит в **Telegram**;
- копия уходит на **вашу почту** через EmailJS.

Если оставить в конфиге `YOUR_PUBLIC_KEY` (и т.д.), письма отправляться не будут — работать будет только Telegram.

Подробнее: папка **ADD** → файл **HOW_TO_IMPLEMENT_REQUESTS.md**.
