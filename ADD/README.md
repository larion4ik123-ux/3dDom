# Проект «Дом 3D» — Визуализация

## Описание проекта
Фотореалистичные визуалы и видео для сайта компании по строительству домов методом 3D-печати.

**География:** Россия  
**Целевая аудитория:** частные заказчики, девелоперы, инвесторы

## Структура проекта

```
dom3d-visualization/
├── README.md
├── TECHNICAL_SPEC.md          # Техническое задание
├── GLOBAL_STYLE.md            # Глобальные стилистические требования
├── block1-technology/          # BLOCK 1: ТЕХНОЛОГИЯ СТРОИТЕЛЬСТВА
├── block2-readiness/           # BLOCK 2: УРОВНИ ГОТОВНОСТИ ДОМА
├── block3-projects/            # BLOCK 3: ПРОЕКТЫ ДОМОВ
├── block4-landing/             # BLOCK 4: КЛЮЧЕВОЙ ВИЗУАЛ ЛЕНДИНГА
├── block5-video/               # BLOCK 5: ВИДЕО
└── assets/                     # Референсы и ресурсы
    ├── references/
    └── textures/
```

## Глобальные требования стиля

- **Инженерный реализм, технологичность, точность**
- **НИКАКОЙ** художественной стилизации, футуризма, sci-fi
- Визуалы выглядят как реальные строительные фото / BIM / CAD-визуализация
- Реальные пропорции, реальные материалы
- Портальный строительный 3D-принтер (industrial concrete 3D printer)
- Нейтральный дневной свет
- Чистый фон, без лишнего окружения
- Формат изображений: **4:3**
- Высокое разрешение, резкий фокус

## Блоки проекта

### BLOCK 1: ТЕХНОЛОГИЯ СТРОИТЕЛЬСТВА
6 изображений — ключевые этапы строительства

### BLOCK 2: УРОВНИ ГОТОВНОСТИ ДОМА
4 изображения — один дом, один ракурс, разные стадии

### BLOCK 3: ПРОЕКТЫ ДОМОВ
5 проектов × 6-8 изображений = 30-40 изображений

### BLOCK 4: КЛЮЧЕВОЙ ВИЗУАЛ ЛЕНДИНГА
1 композиционное изображение

### BLOCK 5: ВИДЕО
1 таймлапс-ролик (20-40 секунд)
