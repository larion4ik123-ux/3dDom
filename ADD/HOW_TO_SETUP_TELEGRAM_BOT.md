# Как настроить Telegram бота для заявок

## 🚀 Пошаговая инструкция

### Шаг 1: Создание бота (3 минуты)

1. **Откройте Telegram** на телефоне или компьютере

2. **Найдите BotFather:**
   - В поиске Telegram введите: `@BotFather`
   - Или перейдите по ссылке: [https://t.me/botfather](https://t.me/botfather)
   - Нажмите "Запустить" или "Start"

3. **Создайте нового бота:**
   - Отправьте команду: `/newbot`
   - BotFather спросит имя бота (например: `Home3D Requests Bot`)
   - Затем попросит username (должен заканчиваться на `bot`, например: `home3d_requests_bot`)

4. **Получите токен:**
   - После создания BotFather покажет токен
   - Токен выглядит так: `123456789:ABCdefGHIjklMNOpqrsTUVwxyz`
   - ⚠️ **ВАЖНО:** Сохраните токен! Он понадобится для настройки сайта

---

### Шаг 2: Настройка бота (опционально)

Вы можете настроить бота дополнительно:

1. **Описание бота:**
   ```
   /setdescription
   ```
   - Выберите вашего бота
   - Введите описание (например: "Бот для получения заявок с сайта Home3D")

2. **Команды бота:**
   ```
   /setcommands
   ```
   - Выберите вашего бота
   - Добавьте команды (например: `/start - Начать работу`)

3. **Аватар бота:**
   ```
   /setuserpic
   ```
   - Выберите вашего бота
   - Отправьте изображение для аватара

---

### Шаг 3: Создание канала/группы для заявок (5 минут)

#### Вариант A: Telegram канал (рекомендуется)

**Преимущества:**
- ✅ Все участники получают уведомления
- ✅ Можно добавить много пользователей
- ✅ Удобно для команды

**Инструкция:**

1. **Создайте канал:**
   - В Telegram нажмите "Новый канал" (или "New Channel")
   - Назовите канал (например: "Home3D Заявки")
   - Добавьте описание (опционально)
   - Выберите тип: Публичный или Приватный

2. **Добавьте бота в канал:**
   - Откройте настройки канала (иконка шестерёнки)
   - Перейдите в "Администраторы" → "Добавить администратора"
   - Найдите вашего бота по username (например: `@home3d_requests_bot`)
   - Дайте права:
     - ✅ Отправлять сообщения
     - ❌ Остальные права не нужны
   - Нажмите "Готово"

3. **Добавьте пользователей в канал:**
   - Откройте настройки канала
   - Перейдите в "Подписчики" → "Добавить подписчика"
   - Выберите пользователей, которые должны получать заявки
   - Или создайте ссылку-приглашение и отправьте им

#### Вариант B: Telegram группа

**Инструкция:**

1. **Создайте группу:**
   - В Telegram нажмите "Новая группа"
   - Добавьте участников
   - Назовите группу (например: "Home3D Заявки")

2. **Добавьте бота в группу:**
   - Откройте настройки группы
   - Перейдите в "Администраторы" → "Добавить администратора"
   - Найдите вашего бота
   - Дайте права: "Отправлять сообщения" ✅

### Шаг 4: Получение Chat ID (2 минуты)

Chat ID нужен для того, чтобы бот знал, куда отправлять сообщения.

#### Способ 1: Через бота @getidsbot (самый простой)

1. Найдите бота [@getidsbot](https://t.me/getidsbot) в Telegram
2. Добавьте его в ваш канал/группу
3. Отправьте любое сообщение в канал/группу
4. Бот покажет Chat ID канала/группы

#### Способ 2: Через API Telegram

1. Напишите вашему боту любое сообщение (если это личный чат)
2. Откройте в браузере:
   ```
   https://api.telegram.org/botВАШ_ТОКЕН/getUpdates
   ```
   (Замените `ВАШ_ТОКЕН` на токен из шага 1)

3. Найдите в ответе:
   ```json
   "chat":{"id":-1001234567890}
   ```
   - Для канала/группы ID начинается с `-100`
   - Для личного чата ID - обычное число

4. **Скопируйте Chat ID** (например: `-1001234567890`)

#### Способ 3: Через бота @userinfobot (для личного чата)

1. Найдите бота [@userinfobot](https://t.me/userinfobot)
2. Начните с ним диалог
3. Он покажет ваш Chat ID

### Шаг 5: Подключение к сайту (3 минуты)

1. **Откройте файл `js/main.js`**

2. **Добавьте конфигурацию в начало файла:**

```javascript
// Конфигурация Telegram
const TELEGRAM_CONFIG = {
    BOT_TOKEN: 'ВАШ_ТОКЕН_ОТ_BOTFATHER',  // Токен из шага 1
    CHAT_ID: 'ВАШ_CHAT_ID'                 // Chat ID из шага 4
};
```

3. **Замените значения:**
   - `ВАШ_ТОКЕН_ОТ_BOTFATHER` → токен бота из шага 1
   - `ВАШ_CHAT_ID` → Chat ID канала/группы из шага 4

4. **Добавьте функции отправки** (из `js/main-telegram-email-complete.js` или `js/main-telegram-complete.js`)

5. **Замените функцию `handleFormSubmit`** на версию с Telegram

## 🔧 Дополнительные настройки

### Настройка уведомлений в канале

1. Откройте канал в Telegram
2. Нажмите на название канала
3. Перейдите в "Уведомления"
4. Настройте:
   - Звуковые уведомления
   - Показ превью
   - Вибрация

### Добавление новых пользователей

**В канал:**
1. Откройте настройки канала
2. "Подписчики" → "Добавить подписчика"
3. Выберите пользователей

**В группу:**
1. Откройте настройки группы
2. "Добавить участника"
3. Выберите пользователей

### Изменение прав бота

1. Откройте настройки канала/группы
2. "Администраторы" → выберите бота
3. Измените права (обычно достаточно "Отправлять сообщения")

## 🚨 Решение проблем

### Проблема: Бот не отправляет сообщения в канал

**Решение:**
1. ✅ Проверьте, что бот добавлен в канал как администратор
2. ✅ Проверьте права бота (должен иметь "Отправлять сообщения")
3. ✅ Проверьте правильность Chat ID (для канала должен начинаться с `-100`)
4. ✅ Убедитесь, что бот не был удалён из канала

### Проблема: Ошибка "chat not found"

**Решение:**
1. ✅ Проверьте правильность Chat ID
2. ✅ Убедитесь, что бот добавлен в канал/группу
3. ✅ Отправьте сообщение в канал/группу, чтобы бот "узнал" его

### Проблема: Ошибка "bot was blocked by the user"

**Решение:**
1. ✅ Это означает, что пользователь заблокировал бота
2. ✅ Для канала/группы это не проблема - бот работает для всех участников

### Проблема: Не все пользователи получают уведомления

**Решение:**
1. ✅ Убедитесь, что пользователи добавлены в канал/группу
2. ✅ Проверьте настройки уведомлений у пользователей в Telegram
3. ✅ Убедитесь, что канал/группа не отключена в уведомлениях

## 🔒 Безопасность

⚠️ **Важно:**

1. **Не публикуйте токен бота** в открытом доступе
2. **Ограничьте права бота** - дайте только "Отправлять сообщения"
3. **Используйте приватный канал**, если не хотите, чтобы его видели все
4. **Для продакшена** рассмотрите вариант с промежуточным сервером (токен будет на сервере, а не в коде)
