# Сайт Home3D — Строительство домов методом 3D-печати

## Описание проекта

Презентационный сайт для компании, занимающейся строительством жилых домов методом 3D-печати. Сайт создан согласно техническому заданию и включает все необходимые разделы.

```

├── readiness-levels.html       # Раздел "Уровни готовности дома"

│   └── projects.js            # Логика карусели проектов
└── SITE_README.md             # Этот файл
```

## Использование

### Локальный запуск

1. Откройте `index.html` в браузере
2. Все страницы связаны через навигацию
3. Для разработки можно использовать локальный сервер:
   ```bash
   # Python
   python -m http.server 8000
   
   # Node.js (http-server)
   npx http-server
   ```

### Замена изображений

Все изображения помечены как placeholder'ы. Для замены:

1. **Hero-блок** (`index.html`):
   - Найдите `.hero-image-placeholder`
   - Замените на `<img src="images/hero.jpg" alt="...">`

2. **Этапы технологии** (`technology.html`):
   - Найдите `.step-image-placeholder`
   - Замените на реальные изображения этапов

3. **Проекты** (`projects.html`):
   - Найдите `.gallery-image-placeholder` и `.thumbnail-placeholder`
   - Замените на изображения проектов

4. **Уровни готовности** (`readiness-levels.html`):
   - Найдите `.level-image-placeholder`
   - Замените на изображения одного дома в разных стадиях

### Добавление видео

В разделе технологии (`technology.html`) найдите `.video-placeholder` и замените на:

```html
<video controls>
    <source src="videos/construction-timelapse.mp4" type="video/mp4">
    Ваш браузер не поддерживает видео.
</video>
```

### Настройка контактов

В футере всех страниц найдите секцию контактов и обновите:
- Email: `info@home3d.ru`
- Телефон: `+7 (XXX) XXX-XX-XX`

### Интеграция формы заявки

Текущая форма имитирует отправку. Для реальной интеграции:

1. Создайте backend endpoint для обработки заявок
2. В `js/main.js` найдите функцию `handleFormSubmit`
3. Замените имитацию на реальный AJAX-запрос:

```javascript
fetch('/api/request', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify(formData)
})
.then(response => response.json())
.then(data => {
    showMessage(form, 'Спасибо! Ваша заявка отправлена.', false);
})
.catch(error => {
    showMessage(form, 'Ошибка отправки. Попробуйте позже.', true);
});
```
