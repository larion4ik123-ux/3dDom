# Telegram для всех форм заявок

## ✅ Да, решение подходит для всех заявок на сайте!

На сайте есть **2 формы заявок**:

1. **Основная форма заявки** (`index.html`) - простая форма с полями:
   - Имя
   - Телефон
   - Email
   - Сообщение

2. **Форма индивидуального проекта** (`custom-project.html`) - расширенная форма с дополнительными полями:
   - Имя
   - Телефон
   - Email
   - Площадь дома
   - Количество этажей
   - Уровень готовности
   - Сообщение

## 🔧 Решение

Код в `js/main-telegram-complete.js` обрабатывает **обе формы** автоматически:

- ✅ Определяет тип формы
- ✅ Собирает все поля (включая дополнительные)
- ✅ Форматирует сообщение в зависимости от типа заявки
- ✅ Отправляет в Telegram с полной информацией

## 🚀 Как подключить

1. **Откройте `js/main.js`**

2. **Добавьте в начало файла (после других констант):**
   ```javascript
   // Конфигурация Telegram
   const TELEGRAM_CONFIG = {
       BOT_TOKEN: 'ВАШ_ТОКЕН',
       CHAT_ID: 'ВАШ_CHAT_ID'
   };
   ```

3. **Добавьте функции `sendToTelegram` и `escapeMarkdown`** (из `js/main-telegram-complete.js`)

4. **Замените функцию `handleFormSubmit`** на версию из `js/main-telegram-complete.js`

5. **Замените значения:**
   - `ВАШ_ТОКЕН` → токен от @BotFather
   - `ВАШ_CHAT_ID` → ваш Chat ID

## ✅ Что получится

- ✅ Все заявки (обычные и индивидуальные) будут приходить в Telegram
- ✅ В сообщениях будет вся информация из формы
- ✅ Для индивидуальных проектов будут показаны дополнительные поля
- ✅ Одна настройка работает для всех форм

## 📝 Важно

Текущий код в `js/main.js` уже обрабатывает обе формы:
- `requestForm` → `handleFormSubmit(form, 'request')`
- `customProjectForm` → `handleFormSubmit(form, 'custom')`

Нужно только заменить функцию `handleFormSubmit` на версию с Telegram, и всё будет работать для всех форм автоматически!
