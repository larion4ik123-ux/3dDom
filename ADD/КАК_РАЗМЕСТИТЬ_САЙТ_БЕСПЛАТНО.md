# Как разместить сайт ДОМ 3Д бесплатно

Сайт состоит из статических файлов (HTML, CSS, JS, изображения). Ниже — несколько бесплатных способов размещения.

---

## 1. GitHub Pages (рекомендуется)

**Плюсы:** бесплатно, неограниченно, свой поддомен `ваш-логин.github.io` или отдельный домен.

### Шаги

1. **Зарегистрируйтесь на [GitHub](https://github.com)** (если ещё нет аккаунта).

2. **Создайте новый репозиторий:**
   - Нажмите «New repository».
   - Имя, например: `dom3d` или `3dhouses`.
   - Public, без README — создать репозиторий.

3. **Загрузите файлы сайта:**
   - В папке проекта откройте терминал (PowerShell или «Терминал» в VS Code).
   - Выполните по очереди:

   ```powershell
   cd "C:\Users\lario\Desktop\3Dhouses"
   git init
   git add .
   git commit -m "Первый коммит — сайт ДОМ 3Д"
   git branch -M main
   git remote add origin https://github.com/ВАШ_ЛОГИН/ИМЯ_РЕПОЗИТОРИЯ.git
   git push -u origin main
   ```

   Вместо `ВАШ_ЛОГИН` и `ИМЯ_РЕПОЗИТОРИЯ` подставьте свой логин и имя репозитория. Git может попросить логин и пароль (или токен) GitHub.

4. **Включите GitHub Pages:**
   - В репозитории: **Settings** → **Pages**.
   - В блоке **Source** выберите ветку **main** и папку **/ (root)**.
   - Сохраните (Save).

5. **Адрес сайта** будет таким:  
   `https://ВАШ_ЛОГИН.github.io/ИМЯ_РЕПОЗИТОРИЯ/`  
   (например: `https://ivanov.github.io/dom3d/`).

**Важно:** если сайт открывается по адресу с путём (например `/dom3d/`), все ссылки в коде должны быть относительными (как сейчас: `index.html`, `technology.html` и т.д.) — так и есть, менять ничего не нужно.

## 2. Netlify (без регистрации в Git)

**Плюсы:** можно залить архив с сайтом перетаскиванием в браузере, бесплатный HTTPS и поддомен.

### Если картинки не показываются и страницы не переключаются

Так бывает, когда в Netlify попал только один файл (`index.html`) или неправильная папка. Нужно загрузить **полный набор файлов**: все 6 страниц HTML, папки `css`, `images`, `js`.

**Проще всего — использовать готовый архив:**

1. В папке `3Dhouses` найдите файл **`Собрать_для_Netlify.ps1`**.
2. Щёлкните по нему правой кнопкой → **«Выполнить с помощью PowerShell»** (или откройте PowerShell в этой папке и введите: `.\Собрать_для_Netlify.ps1`).
3. В папке появится архив **`DOM3D-netlify-deploy.zip`** — в нём уже всё нужное для сайта.
4. Зайдите на **[app.netlify.com](https://app.netlify.com)** → **Sites** → **Add new site** → **Deploy manually**.
5. В окно **перетащите именно этот ZIP-файл** (`DOM3D-netlify-deploy.zip`), а не папку.
6. Дождитесь окончания загрузки. После деплоя картинки и переходы по страницам должны работать.

### Шаги вручную (без скрипта)

1. Зайдите на **[netlify.com](https://www.netlify.com)**.

2. Нажмите **«Add new site»** → **«Deploy manually»** (или «Drag and drop»).

3. В архив для загрузки должны попасть **в корень** (не внутрь подпапки):
   - файлы: `index.html`, `technology.html`, `advantages.html`, `readiness-levels.html`, `custom-project.html`, `projects.html`;
   - папки: `css` (с `style.css`), `images` (со всеми картинками и подпапками), `js` (с `main.js`, `projects.js`).
   
   Либо перетащите в Netlify **содержимое** папки `3Dhouses` (все перечисленные файлы и папки), а не саму папку `3Dhouses`.

4. Netlify загрузит файлы и выдаст ссылку вида:  
   `https://случайное-имя.netlify.app`.

5. В настройках сайта можно сменить имя на что-то вроде `dom3d.netlify.app`.

Дальнейшие обновления: снова запустить скрипт и загрузить новый ZIP или перетащить обновлённую папку. Можно также подключить Git (как в разделе про GitHub) — тогда сайт будет обновляться при каждом `git push`.

**Важно:** в коде используются относительные пути (`images/...`, `css/style.css`, `technology.html` и т.д.). Так сайт одинаково работает и при открытии с диска (двойной клик по `index.html`), и на Netlify после загрузки полного ZIP.

## 3. Cloudflare Pages

**Плюсы:** бесплатно, быстрая раздача, можно подключить свой домен.

1. Зайдите на **[pages.cloudflare.com](https://pages.cloudflare.com)**.
2. **Create a project** → **Direct Upload**.
3. Заархивируйте папку `3Dhouses` (в ZIP должны быть корневые файлы: `index.html`, папки `css`, `images`, `js`).
4. Загрузите архив и нажмите **Deploy**.
5. Сайт получит адрес вида `ваш-проект.pages.dev`.

---

## 4. Vercel

1. Зайдите на **[vercel.com](https://vercel.com)** и войдите (можно через GitHub).
2. **Add New** → **Project**.
3. Импортируйте репозиторий с GitHub (если вы уже залили проект туда) или загрузите папку через **Vercel CLI**.
4. Домен будет вида `ваш-проект.vercel.app`.

## Что выбрать

| Способ           | Сложность | Обновления                    |
|------------------|-----------|-------------------------------|
| **GitHub Pages** | Средняя   | Через `git push`             |
| **Netlify**      | Легко     | Перетаскивание или Git       |
| **Cloudflare**   | Легко     | Загрузка нового ZIP          |
| **Vercel**       | Средняя   | Через Git или CLI            |

Для начала проще всего попробовать **Netlify** (перетащил папку — сайт уже в сети). Если планируете править сайт и выкладывать обновления через Git — удобнее **GitHub Pages** или Netlify с подключённым репозиторием.

---

## Если купите свой домен

На любом из сервисов выше в настройках сайта можно указать свой домен (например `dom3d.ru`). Обычно это пункт **Domain settings** / **Custom domain**; сервис подскажет, какие записи добавить у регистратора домена.

## Формы (заявки) на сайте

Сейчас форма отправляет данные в **Telegram** и при желании в **EmailJS**. Это работает и с бесплатного хостинга: запросы идут с браузера пользователя прямо в Telegram/EmailJS. Никакого своего сервера не нужно. Убедитесь только, что в `js/main.js` указаны ваши токен Telegram и при необходимости настройки EmailJS.
