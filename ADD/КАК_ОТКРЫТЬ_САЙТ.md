# 🚀 Как открыть сайт

## ✅ Способ 1: Открыть файл напрямую (САМЫЙ ПРОСТОЙ)

1. Откройте папку проекта: `c:\Users\lario\Desktop\3Dhouses`
2. Найдите файл `index.html`
3. Дважды кликните на него
4. Сайт откроется в браузере по умолчанию

**Или:**
- Дважды кликните на файл `ОТКРЫТЬ_САЙТ.bat` в папке проекта

---

## ✅ Способ 2: Через локальный сервер (если установлен Python)

1. Откройте терминал в папке проекта
2. Выполните: `python -m http.server 8000`
3. Откройте в браузере: `http://localhost:8000`

---

## ✅ Способ 3: Через VS Code (рекомендуется для разработки)

1. Установите расширение **"Live Server"** в VS Code
2. Откройте папку проекта в VS Code
3. Правый клик на `index.html` → **"Open with Live Server"**

---

## ⚠️ Если изображения не отображаются:

1. **Проверьте консоль браузера** (нажмите F12)
2. Убедитесь, что файлы находятся в папке `images/technology/`
3. Проверьте пути к изображениям в HTML файлах

---
