## ✅ ТРЕБОВАНИЯ К ИЗОБРАЖЕНИЯМ

### **Технические характеристики:**
- **Формат:** JPG или PNG (рекомендуется JPG для фотографий)
- **Соотношение сторон:** 4:3 (например, 1920×1440px) или 16:9 для Hero-изображения
- **Разрешение:** минимум 1920px по большей стороне
- **Размер файла:** оптимизированные для веба (рекомендуется до 500KB на изображение)
- **Качество:** высокое, но сжатое для быстрой загрузки

### **Рекомендации:**
- Используйте инструменты для оптимизации: TinyPNG, ImageOptim, Squoosh
- Всегда указывайте описательный alt-текст для доступности и SEO
- Используйте осмысленные имена файлов (не `IMG_1234.jpg`)

## 🔧 ПОШАГОВАЯ ИНСТРУКЦИЯ

### **ШАГ 1: Создайте структуру папок**

Создайте все необходимые папки в папке `images/`:
- `hero/`
- `technology/`
- `advantages/`
- `readiness/`
- `projects/project-1/` до `project-5/`
- `custom/`

### **ШАГ 2: Подготовьте изображения**

1. Подготовьте все изображения согласно списку выше
2. Оптимизируйте их размер (сожмите для веба)
3. Переименуйте файлы согласно структуре
4. Поместите файлы в соответствующие папки

### **ШАГ 3: Замените placeholder'ы в HTML**

Для каждого placeholder'а в HTML файлах:
1. Найдите `<div class="...-placeholder">`
2. Замените на тег `<img>` с правильным путем
3. Добавьте alt-текст

### **ШАГ 4: Добавьте CSS стили**

Убедитесь, что в `css/style.css` есть стили для всех классов изображений (см. раздел ниже).

### **ШАГ 5: Проверьте результат**

1. Откройте сайт в браузере
2. Проверьте, что все изображения загружаются
3. Проверьте адаптивность на разных устройствах
4. Убедитесь, что изображения не искажаются

## 🎨 CSS СТИЛИ ДЛЯ ИЗОБРАЖЕНИЙ

Добавьте следующие стили в файл `css/style.css` (если их еще нет):

```css
/* ============================================
   Стили для изображений
   ============================================ */

/* Hero изображение */
.hero-image {
    width: 100%;
    height: auto;
    border-radius: 8px;
    object-fit: cover;
    box-shadow: 0 4px 12px var(--shadow-medium);
}

/* Изображения этапов технологии */
.step-image {
    width: 100%;
    height: auto;
    border-radius: 8px;
    object-fit: cover;
    box-shadow: 0 2px 8px var(--shadow-light);
}

/* Изображения преимуществ */
.advantage-image {
    width: 100%;
    height: auto;
    border-radius: 8px;
    object-fit: cover;
    box-shadow: 0 2px 8px var(--shadow-light);
}

/* Изображения уровней готовности */
.level-image {
    width: 100%;
    height: auto;
    border-radius: 8px;
    object-fit: cover;
    box-shadow: 0 2px 8px var(--shadow-light);
}

.finishing-image {
    width: 100%;
    height: auto;
    border-radius: 8px;
    object-fit: cover;
    box-shadow: 0 2px 8px var(--shadow-light);
    transition: transform 0.3s ease;
}

.finishing-image:hover {
    transform: scale(1.02);
}

/* Галерея проектов */
.gallery-main-image {
    width: 100%;
    height: auto;
    border-radius: 8px;
    object-fit: cover;
    box-shadow: 0 4px 12px var(--shadow-medium);
}

.thumbnail-image {
    width: 100%;
    height: 100%;
    object-fit: cover;
    border-radius: 4px;
    cursor: pointer;
    transition: opacity 0.3s ease;
}

.thumbnail-image:hover {
    opacity: 0.8;
}

/* Изображения в быстрых ссылках */
.link-image {
    width: 100%;
    height: auto;
    object-fit: cover;
    border-radius: 8px 8px 0 0;
    transition: transform 0.3s ease;
}

.link-image:hover {
    transform: scale(1.05);
}

/* Изображения в таймлайне */
.timeline-image {
    width: 100%;
    height: auto;
    border-radius: 8px;
    object-fit: cover;
    box-shadow: 0 2px 8px var(--shadow-light);
}

/* Адаптивность для мобильных устройств */
@media (max-width: 768px) {
    .hero-image,
    .step-image,
    .advantage-image,
    .level-image,
    .gallery-main-image {
        border-radius: 4px;
    }
}
```
