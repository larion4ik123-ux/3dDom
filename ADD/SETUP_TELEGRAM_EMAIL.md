# Настройка: Telegram для всех + Email дублирование

## 🎯 Что получится

- ✅ **Все пользователи бота получают уведомления** - заявки приходят в Telegram канал/группу
- ✅ **Дублирование на Email** - каждая заявка также отправляется на email
- ✅ **Надёжность** - если один канал не работает, второй сработает

---

## 📋 Пошаговая настройка

### Шаг 1: Настройка Telegram канала/группы (5 минут)

#### Вариант A: Telegram канал (рекомендуется)

1. **Создайте канал в Telegram:**
   - Откройте Telegram
   - Нажмите "Новый канал"
   - Назовите канал (например: "Home3D Заявки")
   - Сделайте канал публичным или приватным (по желанию)

2. **Добавьте бота в канал:**
   - Откройте настройки канала
   - Перейдите в "Администраторы"
   - Нажмите "Добавить администратора"
   - Найдите вашего бота (по username)
   - Дайте права: "Отправлять сообщения" ✅

3. **Добавьте пользователей в канал:**
   - Все, кого вы добавите в канал, будут получать уведомления о новых заявках
   - Или сделайте канал публичным и дайте ссылку-приглашение

4. **Получите Chat ID канала:**
   - Добавьте бота [@getidsbot](https://t.me/getidsbot) в канал
   - Или отправьте сообщение в канал
   - Откройте в браузере: `https://api.telegram.org/botВАШ_ТОКЕН/getUpdates`
   - Найдите Chat ID (обычно начинается с `-100`)

#### Вариант B: Telegram группа

1. **Создайте группу в Telegram:**
   - Откройте Telegram
   - Нажмите "Новая группа"
   - Добавьте участников
   - Назовите группу (например: "Home3D Заявки")

2. **Добавьте бота в группу:**
   - Откройте настройки группы
   - Перейдите в "Администраторы"
   - Добавьте вашего бота как администратора
   - Дайте права: "Отправлять сообщения" ✅

3. **Получите Chat ID группы:**
   - Отправьте сообщение в группу
   - Откройте: `https://api.telegram.org/botВАШ_ТОКЕН/getUpdates`
   - Найдите Chat ID (обычно начинается с `-`)

### Шаг 2: Настройка EmailJS (5 минут)

1. **Зарегистрируйтесь на [EmailJS](https://www.emailjs.com/)**

2. **Настройте Email сервис:**
   - Перейдите в "Email Services"
   - Добавьте ваш email провайдер (Gmail, Outlook и т.д.)
   - Запишите **Service ID**

3. **Создайте шаблон письма:**
   - Перейдите в "Email Templates"
   - Создайте новый шаблон
   - Используйте такой шаблон:

**Тема:**
```
Новая заявка с сайта Home3D
```

**Содержимое (HTML):**
```html
<h2>Новая заявка с сайта Home3D</h2>

<p><strong>Тип заявки:</strong> {{form_type}}</p>
<p><strong>Дата:</strong> {{date}}</p>

<hr>

<p><strong>Имя:</strong> {{name}}</p>
<p><strong>Телефон:</strong> {{phone}}</p>
<p><strong>Email:</strong> {{email}}</p>

{{#if area}}
<p><strong>Площадь дома:</strong> {{area}} м²</p>
{{/if}}

{{#if floors}}
<p><strong>Этажность:</strong> {{floors}}</p>
{{/if}}

{{#if readiness}}
<p><strong>Уровень готовности:</strong> {{readiness}}</p>
{{/if}}

<p><strong>Сообщение:</strong></p>
<p>{{message}}</p>

<hr>
<p style="color: #666; font-size: 12px;">Заявка отправлена с сайта Home3D</p>
```

4. **Получите ключи:**
   - **Public Key** - из раздела "Account"
   - **Service ID** - из настроек сервиса
   - **Template ID** - из шаблона

---

### Шаг 3: Подключение к сайту (3 минуты)

**1. Добавьте скрипт EmailJS в `<head>` всех HTML страниц:**

Откройте `index.html`, `technology.html`, `advantages.html` и т.д.

Найдите строку:
```html
<script src="js/main.js"></script>
```

Перед ней добавьте:
```html
<script src="https://cdn.jsdelivr.net/npm/@emailjs/browser@4/dist/email.min.js"></script>
```

**2. Обновите `js/main.js`:**

- Замените функцию `handleFormSubmit` на версию из `js/main-telegram-email-complete.js`
- Добавьте функции `sendToTelegram`, `sendToEmail`, `sendRequest` и `escapeMarkdown`
- Добавьте конфигурацию в начало файла:

```javascript
// Конфигурация Telegram
const TELEGRAM_CONFIG = {
    BOT_TOKEN: 'ВАШ_ТОКЕН_ОТ_BOTFATHER',
    CHAT_ID: 'ВАШ_CHAT_ID_КАНАЛА_ИЛИ_ГРУППЫ'  // Chat ID канала/группы
};

// Конфигурация EmailJS
const EMAILJS_CONFIG = {
    PUBLIC_KEY: 'ВАШ_PUBLIC_KEY',
    SERVICE_ID: 'ВАШ_SERVICE_ID',
    TEMPLATE_ID: 'ВАШ_TEMPLATE_ID'
};

// Инициализация EmailJS
if (typeof emailjs !== 'undefined') {
    emailjs.init(EMAILJS_CONFIG.PUBLIC_KEY);
}
```

**3. Замените значения:**
- `ВАШ_ТОКЕН_ОТ_BOTFATHER` → токен бота
- `ВАШ_CHAT_ID_КАНАЛА_ИЛИ_ГРУППЫ` → Chat ID канала/группы
- `ВАШ_PUBLIC_KEY` → Public Key из EmailJS
- `ВАШ_SERVICE_ID` → Service ID из EmailJS
- `ВАШ_TEMPLATE_ID` → Template ID из EmailJS

## ✅ Результат

После настройки:

1. **Заявка отправляется в Telegram канал/группу:**
   - Все участники канала/группы получают уведомление
   - Сообщение красиво отформатировано

2. **Заявка дублируется на Email:**
   - Письмо приходит на указанный email
   - В письме вся информация из заявки

3. **Надёжность:**
   - Если Telegram не работает, заявка всё равно отправится на Email
   - Если Email не работает, заявка отправится в Telegram
   - Пользователь увидит сообщение об успешной отправке

## 🚨 Решение проблем

**Проблема:** Уведомления не приходят в канал
- ✅ Проверьте, что бот добавлен в канал как администратор
- ✅ Проверьте права бота (должен иметь право отправлять сообщения)
- ✅ Проверьте правильность Chat ID канала

**Проблема:** Email не отправляется
- ✅ Проверьте настройки EmailJS
- ✅ Проверьте, что скрипт EmailJS подключен
- ✅ Проверьте правильность ключей в конфигурации

**Проблема:** Не все пользователи получают уведомления
- ✅ Убедитесь, что пользователи добавлены в канал/группу
- ✅ Проверьте настройки уведомлений в Telegram у пользователей
